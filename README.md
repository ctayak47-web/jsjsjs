# CrustyLessons

Android-приложение: несколько профилей расписания, виджеты трёх размеров, постоянное уведомление с текущим уроком.

Создатель: @swatlolz
Канал проекта: @CrustySearch

## Структура
app/src/main/ - манифест, Java-код, ресурсы (layout, drawable, xml)

## Установка в AIDE
1. Создай новый проект в AIDE (шаблон Empty Activity, язык Java, пакет com.crusty.lessons).
2. Клонируй репозиторий: git clone <адрес репозитория>
3. Скопируй папку app/src из клона в папку app/src проекта AIDE, заменив файлы.
4. Файл app/build.gradle оставь из шаблона AIDE. Минимальный SDK: 26. Внешних библиотек не нужно.
5. Запусти сборку, разреши уведомления, создай профиль, добавь виджет.
