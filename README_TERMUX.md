# Сборка CrustyChess из Termux на Android

## Важно перед началом

В архиве подготовлен скрипт для сборки и проверки среды, но APK здесь не собран и сборка на самом телефоне не подтверждена. Для Android-приложения нужны **Java + Gradle + Android SDK Platform 35 + Android Build Tools**. Установка одной Java проблему не решает.

На ARM64-устройстве Termux может не запускать стандартные Android SDK command-line tools: многие из них поставляются для Linux `x86_64`. Поэтому скрипт сначала проверяет наличие SDK и не пытается скачивать неподходящие бинарники вслепую.

## 1. Обнови репозитории Termux

Используй актуальный Termux из F-Droid или официального GitHub проекта Termux. Если `pkg install openjdk-17` сообщает `Unable to locate package`, проверь доступные пакеты:

```sh
pkg update
pkg search openjdk
pkg search gradle
```

Если поиск показывает `openjdk-21`, установи его и Gradle:

```sh
pkg install openjdk-21 gradle
java -version
gradle --version
```

Если `openjdk-21` не найден, не вводи команды установки наугад: сначала проверь источник Termux через:

```sh
termux-change-repo
```

Выбери актуальное зеркало **Main repository**, затем повтори `pkg update` и поиск пакетов. Не запускай `termux-setup-storage` повторно без необходимости.

## 2. Проверь Android SDK

Путь к SDK можно задать через `ANDROID_SDK_ROOT`. Скрипт ожидает платформу `platforms/android-35` и далее запускает Gradle:

```sh
cd ~/CrustyChess
bash termux-build.sh
```

Если проект лежит в общей памяти, сначала скопируй его в домашнюю папку Termux, например:

```sh
cp -r ~/storage/shared/Download/CrustyChess ~/CrustyChess
cd ~/CrustyChess
bash termux-build.sh
```

Путь к папке в `Download` может отличаться в зависимости от того, куда распакован архив.

## 3. Если Android SDK отсутствует

Это частое ограничение чистого Termux. Не скачивай случайные SDK-пакеты или `sdkmanager` для `x86_64` — на ARM64 они могут не запускаться. Практичный вариант без AndroidIDE — собрать проект в удалённой среде Linux (например, GitHub Actions) и скачать готовый APK на телефон. Для такой сборки потребуется загрузить исходники в репозиторий; секреты, ключи подписи и пароли в репозиторий не добавляй.

## Результат

При успешной локальной сборке скрипт копирует APK в:

```text
output/CrustyChess-debug.apk
```

Это debug-сборка для установки и проверки, не подписанный release-релиз. Исходный проект остаётся экспериментальным: его README описывает функции, которые пока не подключены или не проверены. Успешная компиляция не означает, что распознавание доски или другие прототипные функции работают корректно.
